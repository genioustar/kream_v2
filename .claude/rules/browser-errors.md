# 브라우저 에러 대응 규칙 (ego lite)

크롤러 실행이나 검증 중 브라우저 쪽에서 에러가 나면 이 규칙의 순서를 한 번만 따른다. 같은 에러를 같은 방법으로 반복하지 않는다. 이 파일은 세션 시작 때 자동으로 읽힌다.

## 적용 대상
ego lite 연결·세션 실패, 페이지 이동 타임아웃, 셀렉터·DOM 불일치, 수집 결과가 비거나 급감, `CrawlBlockedError`(HTTP 403/429).

## 순서 (건너뛰지 않는다)
1. **원장 먼저.** 아래 "알려진 에러 원장"에서 같은 증상을 찾는다. 있으면 기록된 조치만 한다. 원장에 "하지 말 것"으로 적힌 시도는 다시 하지 않는다.
2. **분류.**
   | 종류 | 증상 | 조치 |
   |---|---|---|
   | 차단 | `CrawlBlockedError`, HTTP 403/429, 차단 문구 | 자동 재시도 금지. 실행을 멈추고 사용자에게 보고한다. `/ego-browser`로 우회하거나 페이지를 대신 열어 보지 않는다. |
   | 연결·세션 | ego lite 창 없음, `python chrome.py` 점검 실패 | `python chrome.py`로 연결을 점검하고 한 번만 다시 실행한다. 그래도 안 되면 멈추고 보고한다. |
   | 화면·DOM | 타임아웃, 셀렉터 불일치, 빈 결과, 수집량 급감 | 3번대로 `/ego-browser`에서 실제 화면을 확인한 뒤 원인을 고친다. |
3. **`/ego-browser`로 확인할 때.**
   - 크롤러 프로세스가 끝난 뒤에만 연다. 파이프라인이 같은 ego lite 세션을 쓰는 중이면(다른 에이전트가 실행 중일 수 있다) 열지 않고 기다린다.
   - 먼저 `ego-browser skill`을 실행해 설치된 버전의 안내를 읽는다.
   - TaskSpace는 목표 하나에 하나만 쓴다. 막히거나 시간 초과된 Page를 새 TaskSpace로 우회하지 않는다. 같은 space에서 복구하고, 안 되면 멈추고 묻는다.
   - 동작이 기대와 다르면 맹목적으로 다시 누르지 않고 현재 페이지(스냅샷)를 먼저 본다. 스냅샷으로 충분하면 스크린샷은 찍지 않는다.
   - 로그인, 캡차, 권한 요청처럼 사람이 해야 하는 단계는 `handOff()`로 넘기고 턴을 끝낸다. 사용자가 확인하기 전에는 다시 조작하지 않는다.
   - 쿠키·캐시·저장소를 지우기 전에는 ego-browser Skill의 `references/clearing-state.md`를 읽고, 사용자 승인 없이는 지우지 않는다.
   - 끝나면 `await task.finish({ keep: [] })`를 마지막 라운드에서 한 번만 호출한다. 멈춘 경우에는 호출하지 않는다.
4. **고치기.** 확인한 원인만 최소 변경으로 고친다. 고친 뒤 같은 시나리오를 다시 실행해 증상이 사라졌는지 증거로 확인한다(수집 개수, 샘플 상품 3개, 스냅샷 요지).
5. **두 번 규칙.** 같은 에러에 같은 방법이 2번 실패하면 멈추고, 다른 접근 2~3가지를 제시해 사용자가 고르게 한다.
6. **기록.** 해결했든 못 했든 원장에 한 줄을 더한다(증상, 원인, 한 조치, 하지 말 것, 날짜). 코드를 바꿨다면 `history.md`에도 남긴다.

## 알려진 에러 원장
새 항목은 맨 위에 추가한다. 형식은 "증상 → 원인 → 조치 → 하지 말 것 (날짜)".

- Kream 상세가 짧거나 읽히지 않음 → 일시적 화면 상태였고 차단이 아니었다 → 차단 문구와 HTTP 403/429만 중단 사유로 본다. 짧은 본문은 경고만 남기고 계속한다 → 짧은 본문만으로 전체 검색을 중단하지 말 것 (2026-11-06)
- 같은 날 재실행에서 옛 형식 네이버 체크포인트가 재사용됨 → 체크포인트 `version`이 URL 생성 규칙과 무관하게 같았다 → 저장 형식이 바뀌면 `CHECKPOINT_VERSION`을 올린다 → 형식이 바뀌었는데 version을 그대로 두지 말 것 (2026-11-06)
- HTTP 403/429 → `CrawlBlockedError` → 자동 재시도 없이 중단하고 사이트 제한 안내를 확인한 뒤 다시 실행한다 → 같은 실행 안에서 재시도하거나 브라우저로 우회하지 말 것 (`common/pacing.py`)
